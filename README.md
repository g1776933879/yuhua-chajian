# 羽化面板 插件与脚本

> 羽化面板（yuhua-panel）插件与脚本私人仓库

## 目录结构

```
plugins/
├── WorkBuddy插件.py
├── 中国联通插件.py
├── 商联道插件.py
├── 回收猿旧衣服回收插件.py
├── 太平洋碳普惠插件.py
└── 小米钱包视频福利插件.py
```

## 使用说明

- 所有插件均支持 **呆呆面板 / 青龙面板** 双平台，由面板定时跑量
- 插件文件放置于 `plugins/` 目录
- 羽化面板导入：插件管理 → 导入插件
